# PrintFlowPro

<p align="center">
  <strong>Smart Printing Workflow Management System</strong>
</p>

PrintFlowPro is a modern printing business management application designed to streamline t-shirt printing operations, from order creation to production tracking.

Built for print shops, sublimation businesses, and custom apparel workflows, PrintFlowPro aims to organize orders, designs, inventory, production status, and customer management in one powerful platform.

**Status:** Active Development

PrintFlowPro is currently in the foundation and UI development stage.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/richiedserna-bit/PrintFlowPro.git
```

Go into the project folder:

```bash
cd PrintFlowPro
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
